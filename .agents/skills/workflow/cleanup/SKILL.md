# Cleanup and review

Clean work that is already implemented. Preserve behavior and public contracts. Do not add features or redesign unrelated modules.

Use one primary agent. Do not delegate or run external review tools unless the user explicitly requests them.

Read the root `AGENTS.md` before you edit. Use [CHECKLISTS.md](CHECKLISTS.md) when the diff needs detailed cleanup heuristics.

## Scope

- Review the complete current diff once.
- Read immediate callers, contracts, and tests only when they are needed to confirm behavior.
- Do not expand into unrelated refactors, API redesign, or product changes.

## Workflow

### 1. Inspect

- Read `git status --short`, `git diff --stat`, and the complete diff.
- Identify behavior, routing contracts, and user-visible copy that must stay unchanged.
- Reuse valid check results from the build phase when their inputs did not change.

### 2. Clean

Apply one bounded pass:

1. Remove dead code, unused imports, debug output (`console.log`), temporary helpers, and stale comments.
2. Simplify control flow and names.
3. Collapse duplication only when the result has less code and less cognitive load.
4. Remove pass-through abstractions. Do not add a new abstraction for speculative reuse.
5. Clean tests without weakening behavior assertions.

### 3. Review

Review the final diff for correctness, accessibility, failure handling, and missing focused coverage. Fix evidence-backed issues. Do not perform a repository-wide audit.

### 4. Validate

Start with the smallest command for each changed area:

- `npx eslint <changed files>` before `npm run lint`.
- `npx tsc --noEmit` when types or shared modules changed.
- `npm run build` only when routing, config, or server components changed.
- Expand only when a failure or a high-risk change requires it.

Do not repeat a passing command unless its inputs changed.

## Preserve unless explicitly in scope

- Route paths, `generateStaticParams`, and metadata exports — these are the public surface of the site.
- User-visible copy and page flows.
- Public function and component prop signatures — update all call sites in the same pass if you change one.
- Accessibility affordances: focus order, labels, `alt` text, ARIA attributes, reduced-motion handling.
- The `<!-- BEGIN:nextjs-agent-rules -->` block in `AGENTS.md` — it is regenerated by `next dev`, not hand-maintained. Guidance outside the markers is hand-written and must be preserved.

## Deletion discipline

- **Safe:** unused import, unreachable branch, dead code with no references (grep + types).
- **Needs proof:** exported symbol, feature-flag path, anything referenced by a string key.
- **Do not delete:** anything whose only caller you could not locate.

When unsure, list it as **suspicious** in the final report instead of removing it.

## Done

- The complete diff has one cleanup and review pass.
- Behavior and contracts are preserved.
- Dead code, duplication, debug artifacts, and unnecessary comments are removed.
- Relevant narrow checks pass, or the report states a concrete limitation.

Report the main simplifications, checks, and remaining risks. Keep the report concise.
